# Personal Portfolio – ANISHKA

A basic personal portfolio website built using **HTML5**. It introduces me, showcases my skills and goals, includes a timetable, and provides a contact form.

## Features
- Header with personal introduction.
- Navigation bar with About, Skills, and Contact sections.
- Skills list and personal goals.
- Timetable displayed with subjects and timings.
- Contact form featuring:
  - Name and email fields.
  - Reason for contacting dropdown.
  - Preferred contact method (radio buttons).
  - Message textarea.
  - HTML form validation using `required`, `minlength`, `maxlength`, and `type="email"`.

## Technologies Used
- HTML5

## Purpose
Created as a beginner-level HTML project to practise semantic HTML elements, lists, tables, hyperlinks, forms, and form validation.
